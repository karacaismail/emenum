CSP Directives Added:
  - default-src 'self' → Only allow same-origin resources by default
  - script-src 'self' → Only allow scripts from same origin
  - style-src 'self' 'unsafe-inline' → Allow inline styles (required for Tailwind CSS)
  - img-src 'self' data: https: → Allow QR code data URIs and HTTPS images
  - connect-src 'self' https://*.supabase.co → Allow Supabase API connections
  - font-src 'self' → Only allow same-origin fonts
  - object-src 'none' → Block object/embed/applet elements
  - base-uri 'self' → Restrict base tag to same origin
  - form-action 'self' → Only allow form submissions to same origin
  - frame-ancestors 'none' → Prevent framing (defense-in-depth with X-Frame-Options)
