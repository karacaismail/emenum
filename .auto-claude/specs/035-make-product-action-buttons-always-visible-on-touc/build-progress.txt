=== PROBLEM STATEMENT ===

Product list action buttons (edit, delete, visibility toggle) are only visible on hover, making them inaccessible on touch devices and difficult for keyboard users.

Current Implementation:
- Uses opacity-0 group-hover:opacity-100 pattern
- Buttons are completely hidden until mouse hover
- Touch device users (tablets, phones) cannot access edit/delete actions

Impact:
- High severity - breaks core functionality on touch devices
- Affects restaurant staff who may use tablets for management
- Accessibility issue for keyboard users

=== IMPLEMENTATION STRATEGY ===

Approach:
Change opacity-0 to opacity-70 (or remove entirely) to make buttons always visible while maintaining hover effect for visual feedback.

Options Considered:
1. Remove opacity-0 entirely → Always 100% visible
2. Use opacity-70 → Subtle but visible, becomes 100% on hover
3. Use @media (hover: none) → Touch-specific visibility
4. Use Tailwind md:opacity-0 → Responsive approach

Recommended: Option 2 (opacity-70 group-hover:opacity-100)
- Balances visibility with clean UI
- Maintains hover feedback
- Works on all devices
- Simple CSS change, no media queries needed
