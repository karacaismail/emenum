# Create Reusable Select Component for Consistent Form Styling

## Overview

Add a Select component to the UI library to replace inline-styled select elements across forms, ensuring consistent styling and accessibility.

## Rationale

The Input component exists with proper label, helper text, and error states, but select elements throughout the app use inline Tailwind classes that vary slightly between pages. This creates visual inconsistency and requires duplicating accessibility attributes (aria-describedby, etc.).
