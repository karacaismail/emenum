# Add Skeleton Loading States for Better Perceived Performance

## Overview

Replace spinner-only loading states with skeleton screens that show content placeholders, improving perceived loading speed and reducing layout shift.

## Rationale

The app uses spinner loaders (animate-spin) that don't indicate what content is loading. Skeleton screens provide visual structure that matches the final content, making the app feel faster and preventing jarring layout shifts when content loads.
