# Add Search to Categories Page

## Overview

Add search functionality to the categories page, allowing users to filter categories by name. This mirrors the existing search pattern already implemented in the products page.

## Rationale

The products page at app/(dashboard)/products/page.tsx already has a working search input with searchQuery state and filtering logic. The categories page is missing this feature despite having the same UI component pattern. Direct pattern replication with minimal changes.
